# s9gen5 target (Amlogic S905X5M / S7D) — X96 M200

Goal: new Batocera target `s9gen5` that boots from SD on the X96 M200
(`s7d_s905a_bm221`, 2 GB, Mali-G310, Maxio PHY, RTL8733BS) and reaches
EmulationStation on labwc with the Mali blob.

Validated on the box with CoreELEC 22.0-Piers_beta2 (Generic image,
`s7d_s905x5m_2g_1gbit.dtb`): kernel 5.15, DRM `card0`/HDMI-A-1, mali_kbase,
wifi + ethernet working. Every piece below is taken from CoreELEC
(`projects/Amlogic-ce`, branch coreelec-22).

## Boot chain

Stock u-boot env: `update` → `recovery_from_sdcard` → `fatload aml_autoscript`
→ `autoscr`. CoreELEC's `aml_autoscript` rewrites `bootcmd` to try
`cfgload` from SD/USB first, then `storeboot` (Android). `cfgload` loads an
Android boot image (`kernel.img`: header v0, page 2048, base 0,
kernel_offset 0x2000000, kernel = `Image.lzo`, ramdisk = initrd) and
`dtb.img`, then `bootm`.

For Batocera: same scripts, `kernel.img` = `Image.lzo` + Batocera
`initrd.gz`, bootargs `label=BATOCERA`.

## Tasks

1. `configs/batocera-s9gen5.board` (cortex-a55, CoreELEC kernel +
   common_drivers, Image.lzo, DTBs `amlogic/s7d_s905a_bm221`
   `amlogic/s7d_s905x5m_2g_1gbit`, mali-G310, labwc, no mesa).
2. `batocera-system/Config.in`: target symbol, arch name, images dir, gpu
   name `mali-g310`, GLES3, emulator lists (follow s905gen3).
3. `batocera-initramfs`: gzip initrd like a3gen2.
4. `package/batocera/gpu/mali-G310`: JeffyCN libmali meson build with the
   CoreELEC blob injected (gpu=valhall-g310, version=r44p0,
   platform=wayland-gbm) + CSF firmware.
5. Kernel module packages: `mali-kbase-aml` (gpu-aml valhall r44p0 CSF),
   `rtl8733bs`.
6. `board/batocera/amlogic/s9gen5`: kernel config + fragment, linux
   patches (dtb copy, gpio_data.h, gcc fixes), fsoverlay (module loading),
   `x96-m200/` (create-boot-script, genimage, aml_autoscript, cfgload,
   mkbootimg.py).
7. Build, flash, iterate on the box (serial-less: SSH once network is up).

Later: Bluetooth (rtk_hciattach + rtl8733bs_fw), audio routing, IR remote,
Kodi, media decoders.
